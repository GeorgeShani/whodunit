# scripts/audio: WHODUNIT?! sound build

Everything in `assets/audio/` is generated by these scripts (numpy/scipy synthesis, plus Kenney CC0 samples for three hybrid cues). Documentation: `docs/SOUND_NOTES.md`.

| File | Role |
|---|---|
| `dsp.py` | oscillators, filters, reverb, trim, loudness (pyloudnorm), limiter, `master()` |
| `make_sfx.py` | the original 17 cues (docstring = how each is made); also exports `thunder`, `brass`, `timpani` used by the noir pass |
| `make_noir.py` | the 25 noir-pass cues; each function's docstring says where the cue plays. Beds are periodic by construction |
| `master_all.py` | loudness classes (sting -16, accent -18, foley -20, tap -22, bed -24 LUFS), true-peak check on the decoded ogg AND mp3 (<= -1 dBTP), mono encode, `after_report.json` |
| `measure.py` | ffmpeg ebur128 + astats report (JSON): duration, size, I, LRA, M/S max, true peak, sample peak |
| `loopcheck.py` | loop-seam click check on decoded files |
| `decode_test.mjs` | headless-Chromium decode/play test of every file (desktop + Pixel-7 emulation). Safari/WebKit is not covered |
| `make_docs.py` | table generator used for the docs |
| `fetch_sources.sh` | downloads the Kenney CC0 packs (only for `impact`, `door_slam`, `footsteps_sneak`) |

```bash
python3 -m venv .venv && .venv/bin/pip install numpy scipy soundfile pyloudnorm
./fetch_sources.sh
.venv/bin/python make_sfx.py                                   # legacy masters -> masters/
WHODUNIT_MASTERS=$PWD/masters .venv/bin/python make_noir.py     # new masters   -> masters/
.venv/bin/python master_all.py --legacy masters --new masters   # normalise + encode -> ../../assets/audio
python3 measure.py ../../assets/audio > after.json
```

Requires ffmpeg with libvorbis and libmp3lame. Masters are float WAVs and are not committed.
