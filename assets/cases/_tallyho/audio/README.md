# S.S. Tallyho audio (`assets/cases/_tallyho/audio/`)

Per-case audio folder (decision Q14). Blackwood's sounds stay in `assets/audio/` and are the default. Notes, mapping, measurements and the loader ask: `docs/cases/TALLYHO_SOUND.md`. Licenses: `LICENSES.md`. Rebuild: `scripts/audio/make_tallyho.py`.

- **Cue overrides** use the shared cue's file stem: `case_open`, `door_creak`, `door_slam`. A loader that looks in this folder first picks them up with no data change.
- **Beds** (new stems): `bed_ship_deck`, `bed_ship_interior`, `bed_engine_room`.
